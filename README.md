# Event Agency

Платформа для управления ивент-агентством.

## Роли
- director — полный доступ
- admin — заказы, клиенты, назначение аниматоров
- animator — свои заказы, расписание, статусы

## Стек
- Server: Node.js + Express + PostgreSQL + Prisma + TypeScript
- Mobile: React Native + Expo
- Admin Web: React + Vite
- Shared: TypeScript-типы, роли, права, статусы
