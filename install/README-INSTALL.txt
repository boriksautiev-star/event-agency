================================================
 Event Agency — УСТАНОВКА
================================================

⚠️ ТРЕБОВАНИЯ:
  - Windows Server 2019/2022 (или Windows 10/11 Pro)
  - 4 ГБ RAM (8 ГБ рекомендуется)
  - 20 ГБ свободного места
  - Права Администратора на сервере
  - Интернет

================================================
БЫСТРАЯ УСТАНОВКА (5 минут)
================================================

1. Распакуйте этот архив в C:\EventAgency
   (или другую пустую папку без пробелов и русских букв)

2. Откройте PowerShell ОТ ИМЕНИ АДМИНИСТРАТОРА:
   - Нажмите Win → введите PowerShell
   - Правой кнопкой на "Windows PowerShell"
   - "Запустить от имени администратора"

3. Перейдите в папку установки:
   cd C:\EventAgency\install

4. Запустите установщик:
   powershell -ExecutionPolicy Bypass -File .\install.ps1

5. Следуйте инструкциям в консоли:
   - Путь установки (Enter = C:\EventAgency)
   - Домен (если есть — для HTTPS, иначе Enter)
   - Путь к license.key (если купили лицензию, иначе Enter = демо)
   - Пароль postgres (superuser PostgreSQL — его установит скрипт, если нужно)

6. После завершения:
   - Откройте URL из консоли (например, http://localhost:3100)
   - Пройдите Setup Wizard (создание директора)
   - Токен для setup — в файле C:\EventAgency\install-info.txt

================================================
ЧТО ВНУТРИ АРХИВА
================================================

  install\              — скрипты установки/обновления/удаления
  server\               — backend (Express + Prisma + PostgreSQL)
  admin-web\            — веб-админка (React)
  mobile\               — мобильное приложение (RN/Expo, исходники)
  shared\               — общий код (типы, константы)
  docs\                 — подробная документация
    INSTALL.md          — пошаговая инструкция для админа
    ADMIN-GUIDE.md      — руководство для директора/админа/аниматора
    CHANGELOG.md        — история версий
    LICENSE.md          — лицензионное соглашение
  README.md             — общее описание продукта

================================================
ЧТО ДЕЛАТЬ ПОСЛЕ УСТАНОВКИ
================================================

1. Откройте админ-панель (URL из install-info.txt)
2. Пройдите Setup Wizard → создайте директора
3. Войдите как директор:
   - Сотрудники → добавьте админов и аниматоров
   - Справочники → группы персонажей, персонажи, цены
   - Аниматоры → таб "Шаблоны ставок" → создайте шаблон
   - Настройки → реквизиты агентства, лицензия, push
4. Установите APK мобильного приложения на телефоны сотрудников
5. В APK укажите URL сервера (из install-info.txt)

================================================
ОБНОВЛЕНИЕ (когда выйдет новая версия)
================================================

  cd C:\EventAgency
  powershell -ExecutionPolicy Bypass -File install\update.ps1

Скрипт сам: сделает бэкап БД → остановит службу → обновит код →
применит миграции → запустит службу.

================================================
ПОДДЕРЖКА
================================================

При проблемах:
  1. Проверьте логи: C:\EventAgency\server\logs\service-err.log
  2. Смотрите docs\INSTALL.md → раздел "Решение проблем"
  3. Свяжитесь с разработчиком
