## [1.0.0] — 2026-10-23

Первая production-версия. Готова к продаже агентствам.

### Добавлено

**Система заказов:**
- Заказы со слотами (персонаж + длительность + цена)
- Расписание аниматоров с проверкой пересечений
- Статусы заказа: `new → confirmed → in_progress → completed`, + `cancelled`
- Валидация переходов на сервере (`ORDER_STATUS_FLOW`)
- Кастомные длительности персонажей (1–1440 мин)
- Предоплата и финальный расчёт (нал/перевод), сдача в кассу

**Ставки аниматоров:**
- Rate Templates: шаблоны по группам персонажей + длительностям
- Персональные override на конкретного персонажа
- Автоматический пересчёт payout при изменении шаблона/override
- Привязка шаблона к аниматору

**Передача заказов (handover):**
- Аниматор отправляет заявку другому аниматору
- Получатель принимает/отклоняет
- Админ/директор подтверждает
- Атомарная замена аниматора на заказе
- Push-уведомления на каждом шаге
- Cron-напоминания получателю (каждые 30 мин)
- История передач в отчётах

**Уведомления:**
- Push (Expo/FCM) на мобильные устройства
- События: назначение, ответ, передача, завершение работы, отсутствие бэкапа
- Настройки push-уведомлений (тумблеры, в admin-web и mobile)

**Отчёты:**
- Отчёт по аниматору: заказы, часы, выплаты, отказы, передачи
- Агрегаты по передачам (передал N, получил M, среднее время до approve)
- Единый таймлайн истории (статусы + правки полей)

**Финансы:**
- Учёт предоплат и финальных оплат
- Выплаты аниматорам (нал/перевод)
- Расходы (категории)
- Начисления админам (процент от заказов)
- Касса за месяц

**Бэкапы:**
- Локальные (`pg_dump`) — ежедневно в 03:00 через Task Scheduler
- Ротация 30 дней
- Safety-бэкап перед восстановлением
- S3-совместимые облака (Yandex, VK, AWS, Selectio, MinIO, Backblaze)
- N таргетов, шифрование секретов (AES-256-GCM)
- Проверка «свежести» бэкапа (cron + push-алерт при >25 ч)
- Восстановление из UI (с подтверждением пароля директора)

**Лицензирование:**
- Оффлайн JWT-лицензии (RS256)
- Grace period 10 дней после истечения
- После grace period — блокировка создания новых заказов
- Защита от отката времени
- UI для загрузки `license.key`

**Мобильное приложение:**
- Экран настройки сервера (URL агентства)
- Роли: animator, director, admin
- Профиль с настройками уведомлений
- Передача заказов, отчёты, приём/отклонение

**Веб-панель:**
- Сводка, заказы, клиенты, аниматоры, передачи
- Финансы (доходы, расходы, выплаты)
- Справочники (группы, персонажи)
- Настройки (реквизиты, лицензия, уведомления, бэкапы)
- Сотрудники (только директор)

**Установка:**
- `install/install.ps1` — установка одной командой на Windows Server
- Автоустановка Node.js, PostgreSQL, Git, NSSM, Caddy через winget
- `install/update.ps1` — обновление (git pull + миграции + рестарт)
- `install/uninstall.ps1` — удаление с сохранением/удалением БД
- HTTPS через Caddy с автоматическим сертификатом
- `install-info.txt` с доступами и паролями

**Безопасность:**
- JWT access/refresh токены
- Bcrypt-хеширование паролей
- Ролевая модель доступа (director/admin/animator)
- Проверки прав на всех эндпоинтах

### Исправлено

- Аудит статусов заказа: добавлена валидация недопустимых переходов (B1)
- Единая история изменений (StatusHistory + OrderChange) в одном таймлайне (B3/B4)
- Push при завершении работы аниматором (B5)
- Мёртвый permission `ORDERS_STATUS_OWN` удалён (B6)
- `requirePermission` на роуте смены статуса назначения (B7)
- `new → in_progress` разрешён в FLOW (B8, final-payment)
