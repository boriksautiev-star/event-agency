# Лицензионное соглашение (EULA)

**Event Agency** — программное обеспечение для управления ивент-агентством.

Версия: 1.0.0
Дата: 23 октября 2026 г.

---

## 1. Определения

- **Продукт** — программное обеспечение Event Agency, включающее серверную часть, веб-панель администратора, мобильное приложение и документацию.
- **Лицензиат** — юридическое или физическое лицо, установившее Продукт на свой сервер.
- **Лицензия** — файл `license.key`, содержащий подписанные данные о сроке действия и владельце.
- **Разработчик** — правообладатель Продукта (Borik Sautiev / Event Agency).

---

## 2. Предмет соглашения

Разработчик предоставляет Лицензиату неисключительное, непередаваемое право использования Продукта в объёме, указанном в `license.key`.

**Одна лицензия = одно агентство (один сервер + одна база данных).**

---

## 3. Разрешено

- Установка на сервер, принадлежащий Лицензиату
- Использование в коммерческой деятельности (управление заказами, аниматорами и т. д.)
- Резервное копирование Продукта для внутренних нужд
- Модификация исходного кода для собственных нужд (без права распространения)

---

## 4. Запрещено

- Копирование, распространение, публикация Продукта (в том числе форков) в открытых источниках
- Передача доступа третьим лицам (кроме сотрудников Лицензиата)
- Декомпиляция, обход лицензионной защиты, модификация `license.key`
- Использование на нескольких серверах/агентствах без отдельной лицензии на каждое
- Удаление указателей авторского права

---

## 5. Срок действия

- Лицензия действует в течение срока, указанного в `license.key` (обычно 12 месяцев).
- По истечении срока — **grace period 10 дней** (полная работоспособность + предупреждения).
- После grace period — блокируется создание новых заказов, старые доступны для чтения.
- Продление — по новому `license.key` от Разработчика.

---

## 6. Ограничение ответственности

Продукт предоставляется «как есть». Разработчик **не несёт ответственности** за:
- Потерю данных, упущенную выгоду, простои
- Сбои, вызванные неправильной настройкой сервера Лицензиатом
- Сбои третьих сервисов (PostgreSQL, Let's Encrypt, S3-провайдеры, Firebase/FCM)

**Лицензиат обязуется самостоятельно делать резервные копии БД.** Для этого в Продукте есть встроенная система бэкапов (см. [ADMIN-GUIDE.md](ADMIN-GUIDE.md#бэкапы)).
